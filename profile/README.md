## 🫀 About

**CoraMetix** is a cardiovascular medical device company based in Perth, Western Australia. We combine advanced manufacturing, data infrastructure and machine intelligence to design, build and understand devices that work inside the cardiovascular system.

This organization hosts our engineering tools, simulation workflows and internal utilities.

<br/>

## ⚙️ What we work on

<table>
<tr>
<td width="50%" valign="top">

### 🖨️ MEW Printer Control
Control software for melt electrowriting: motion, temperature, pressure and high-voltage coordination for precise, repeatable fibre deposition.

</td>
<td width="50%" valign="top">

### 🗄️ Database Systems
Structured storage of print parameters, experiments and results, so every scaffold can be traced back to how it was made.

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 👁️ Machine Vision
Imaging pipelines for in-process monitoring and post-print inspection of jets, fibres and scaffold geometry.

</td>
<td width="50%" valign="top">

### 🧠 Deep Learning
Neural models for detection, segmentation and prediction that turn images and process data into actionable feedback.

</td>
</tr>
</table>
